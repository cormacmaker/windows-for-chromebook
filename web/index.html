Windows for Chromebook

Use Windows applications from your Chromebook through your own Windows PC.

Open Windows for Chromebook

How it works

Windows for Chromebook connects your Chromebook to your own Windows PC. The Windows PC runs the Windows applications while your Chromebook provides the interface.

Private by design

Your Windows applications run on your own PC. The project is designed around connecting directly to your computer rather than requiring a central server to run your applications.
